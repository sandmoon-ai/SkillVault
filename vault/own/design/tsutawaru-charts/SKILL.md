# 伝わるデザイン Charts & Figures

做图解、图表、表格，或清理软件默认的「花哨图」。原则：墨水服务于数据与关系，不服务于特效。

## 何时使用

- 新建/重做フロー、对比图、グラフ、表
- 用户抱怨图很土、默认 Excel 图表难看、箭头很乱
- Layout 已定，需要把证据区做成可读視覚

## 工作流

```
Charts Progress:
- [ ] 1. 定目的：比较 / 推移 / 构成 / 流程 / 关系
- [ ] 2. 选型：図解 vs 表 vs グラフ
- [ ] 3. 画结构（少形状、成组、对齐）
- [ ] 4. 去装饰（影/3D/渐变/双描边）
- [ ] 5. 标注与配色（直接、克制）
- [ ] 6. 自检：不靠图例猜、不靠颜色唯一编码
```

## 先选型

| 目的 | 优先 |
|------|------|
| 比较大小/排名 | 棒グラフ、并列表 |
| 时间推移 | 折れ線（少系列） |
| 构成比 | 表或简单棒；円は件数少且要占比故事时慎用 |
| 步骤/流程 | 横/纵ステップ図解 |
| 结构/关系 | 简洁ボックス+線；避免炫技连线网 |
| 精确读数 | 表优先于装饰图 |

一图一个主要读法。两个无关故事 → 拆成两图。

## 図形・囲み・矢印

### 囲み

- **塗りと枠は基本どちらか一方**；双重要素易脏、抢内容
- 囲み用于「集合/注意」；能靠留白分组就不要框
- 全篇囲み风格统一（线宽、圆角、色）

### 角丸

- 角丸は慎重；要用就 **半径统一**
- 避免每层盒子不同圆角度「手作感」

### 装饰默认关掉

删除或勿用：

- 阴影、立体、渐变、发光
- 夸张预设形状、剪贴画风箭头
- 粗金边、纹理填充

软件默认形状通常过炫 → 先剥到平底/细线，再谈强调。

### 矢印

- **柄と矢じりの比率を歪めない**（勿随意拉扁）
- 箭头辅助流向，不比节点文字更抢眼
- 流程方向单一、清晰；少用双向乱箭
- 立体/特效箭头原则上不用

### 図解排版

- 节点尺寸尽量同级一致；对齐到网格
- 线宽统一；交叉尽量少
- 标签靠近所指对象（グループ化）
- 说明文字进组内或贴边，不悬浮太远

## グラフ

### 制作要点

1. 标题写成 **结论句**（如「Q3 新規が主因で売上回復」），避免只写「売上推移」
2. 删 3D、渐变柱、无意义阴影
3. 网格线变淡或删到不影响读数的最少
4. 系列宜少；非必要不双轴
5. 能直接标数据/系列名就减少图例往返
6. 起点与刻度不误导（尤其柱图基线）

### 强调

- 用主色高亮关键系列/关键柱；其余中性灰
- 不要彩虹配色每人一色到看不懂
- 色觉差异：不只靠红绿差；可加图案/标签

### Excel / 默认图清理顺序

1. 关 3D / 阴影 / 渐变  
2. 统一字体到正文体系  
3. 去掉多余刻度线与边框  
4. 收敛颜色  
5. 改结论式标题 + 必要直接标注  

## 表

### 结构

- **删多余框线**；常用：保留横分隔或表头底线，而非满宫格
- 单元格内留白；行高勿贴字
- **数値は右揃え、文言は左揃え**；表头对齐与列类型一致
- 宽表可隔行浅底（很浅），勿高饱和斑马纹
- 表头与正文字重/底区分清楚，但不要厚重底板压内容

### 表 vs 图

- 要精确对比多个指标 → 表
- 要趋势或一眼比较 → 图
- 两者并用时：图给故事，表给细节；不要重复同一堆数两份装饰

## 图中文字与说明

- 图内字号纳入全篇层级（通常 ≤ 正文，关键数字可例外放大）
- 图注/来源用 caption 级，位置稳定（图下或旁）
- 避免字叠在忙乱底图上；必要时空底或半透明蒙皮

## 配色（图表专用）

- 默认：中性灰系 + 1 个强调色讲故事
- 分类色不超过理解负担；类别很多时改表或聚合
- 背景保持白/浅；深色主题也要保证对比
- 打印灰度：用明度差，不只靠色相

## 输出格式

```markdown
# 図表方案

**目的**: [比较/推移/构成/流程/…]
**形式**: [図解/棒/折れ線/表/…]
**一图读法**: …

## 结构
- 元素与层级: …
- 对齐/间距: …
- 标注策略: …

## 样式令
- 形状: 平底/线宽… / 角丸…
- 箭头: …
- 色: 强调… / 其余…
- 禁止: 影・3D・渐变・双枠

## 若基于旧图的改动
1. …
```

直接实现时（SVG/组件/Excel 步骤）：先给结构与样式令，再动手；避免一边画一边加特效。

## 自检清单

- [ ] 目的与图表类型匹配
- [ ] 无影/3D/渐变/夸张箭头
- [ ] 囲み未双重、角丸统一
- [ ] 对齐与成组清楚
- [ ] 标题是结论或明确问题
- [ ] 表：少线、数右文左
- [ ] 不只靠颜色编码

## 反模式

- 默认图表皮肤直接粘贴
- 圆角彩色卡片墙代替结构
- 立体箭头串联「显得专业」
- 一图十二色系列
- 满表框线 + 低对比灰字

## 边界

- 不篡改数据；只改呈现
- 统计诚实优先于「更好看的比例」
- 整页版式交 `tsutawaru-layout`；字体体系交 `tsutawaru-typography`
- 审稿总清单交 `tsutawaru-review`
