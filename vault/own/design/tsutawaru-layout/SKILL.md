# 伝わるデザイン Layout

做版式与改版式。原则：信息先于装饰；统一先于个性；留白是功能，不是浪费。

与 `tsutawaru-review` 分工：Review 找问题；本 skill 直接产出结构与改法。

## 何时使用

- 新建或重做幻灯片、企划书、文档页、チラシ版式
- 用户说「太挤 / 对不齐 / 没重点 / 帮我排一下」
- 已有 Review 结论，需要落成具体布局方案

## 工作流

```
Layout Progress:
- [ ] 1. 定类型、一页主信息、信息层级
- [ ] 2. 定网格：页边、栏、对齐线
- [ ] 3. 摆内容：グループ化 → 揃える → 余白
- [ ] 4. 加強弱与反复样式
- [ ] 5. 配色（少色、够对比）
- [ ] 6. 去噪声（囲み/影/渐变/多余线）
- [ ] 7. 按文档类型做最终约束检查
```

## 先定信息，再排版

动像素前先写清：

1. **这一页唯一主信息**（一句话）
2. **层级**：主标题 → 支持点（≤5）→ 注释/来源
3. **必须出现的对象**：标题、正文/要点、图/表、页码/来源（按需）

若一页塞两个独立结论 → 拆页，或主次降级（一侧主、一侧辅）。

## 五法则（落稿顺序）

### 1. グループ化（先归堆）

- 相关的靠在一起；无关的拉开
- 标题贴所属段落/图，不飘在页中间
- 图与说明成一组；图注不要跑到下一组旁边

### 2. 揃える（再对齐）

- 选一条主对齐边（通常左缘）贯彻全页
- 多栏时：栏宽一致或成明确比例；卡片左缘/上缘齐
- 禁止「肉眼差不多」；用网格/参考线思维描述位置
- 图标+文字：图标盒宽统一，文字左缘齐

### 3. 余白（再透气）

优先级：

1. 页边距（四边留足，勿贴边）
2. 区块间距（组与组 > 组内）
3. 行間/段間（阅读节奏）

经验约束：

- 组内紧、组间松
- 宁肯少字加空，也不满版堆字
- 对象与边框/囲み内侧也要留白

### 4. 強弱（再分主次）

用 **尺寸 > 字重 > 色** 建层级（不要只靠变色）：

| 层级 | 典型做法 |
|------|----------|
| 主标题 | 明显更大/更重 |
| 小見出し | 中号 + 稍重或主色 |
| 正文 | 稳定字号、常规字重 |
| 注释 | 更小或灰色，对比仍可读 |

跳率要够：标题与正文若只差 2pt，看起来仍「糊成一片」。

### 5. 繰り返す（全篇统一）

跨页固定：

- 标题区位置与字号
- 页边距与栏结构
- 强调色与中性色
- 要点符号、図の線幅、角丸半径（若用）

同一套资料里，不要每页重新发明布局语言。

## 视线与结构

- 默认阅读：左上 → 右 → 下（Z/F 近似）
- 主信息放视觉起点附近；次要信息下沉或靠边
- 布局应映射信息结构：并列用并排；流程用横向/纵向步骤；对比用左右两栏

## 配色（服务层级，不抢戏）

默认配色骨架：

- **主色** 1：标题/关键强调
- **中性** 黑/深灰字 + 浅底
- **强调** 1（可选）：数据高亮、CTA
- **背景** 保持安静；照片底慎用，必须压暗/蒙皮保证字对比

约束：

- 色数克制；同类元素同色
- 文字与背景对比充足；避免浅灰字+浅底
- 状态不要只靠颜色（辅以字/形/位置）
- 可能单色打印时，用明度差保证可分

## 去噪声（改稿必做）

默认删除或降级：

- 阴影、立体、渐变填充
- 双重要素的囲み（塗り+枠同时抢眼）
- 过多圆角、每块都套框
- 装饰线、水印式底纹、无意义图标墙
- 3D 图表、夸张箭头、剪贴画风形状

囲み只用在：真正需要「集合」或「注意」时；能用留白分组就不用框。

## 按文档类型的布局配方

### スライド

```
┌─────────────────────────┐
│ 标题（一页一意）            │
│                         │
│  要点 / 图 / 表（主区）     │
│                         │
│  来源（小）          页码  │
└─────────────────────────┘
```

- 一页一个结论；标题尽量是主张，不是主题词
- 远读优先：标题与关键数字够大
- 正文短句/要点；长段改文书页
- 全套页边与标题区锁定

### 企画書 / 大判

- 明确章节見出し带
- 两栏常见：左叙事 / 右图证；或上结论下展开
- 每节开头先结论句，再证据
- 图旁说明成组；避免跨栏「漂移」

### 文書（正文为主）

- 稳定見出し层级（H1/H2/H3 视觉差固定）
- 行长可控；过宽就段组或缩栏
- 段间距统一；少用空行硬堆层级
- 列表与正文对齐体系一致（左缘）

### チラシ / 掲示

```
主视觉/主句（最大）
↓
关键信息（时间・场所・对象）
↓
次要说明
↓
行动指引（报名/二维码/URL）
```

- 3 秒能抓住「是什么 + 要我做什么」
- CTA 位置稳定、对比强
- 信息密度高时更要靠グループ化，而不是更多框

## 改稿时的操作顺序

面对已有乱稿，按此动刀（比「整体美化」有效）：

1. 删装饰（影/渐变/立体/多余枠）
2. 写出一页主信息；删或降级无关块
3. 重做分组与对齐（一条左缘 + 统一间距刻度）
4. 重建字号层级（3–4 级即可）
5. 收色到主色+中性+一点强调
6. 最后微调余白

## 输出格式

做新布局或给改版方案时用：

```markdown
# Layout 方案

**类型**: …
**一页主信息**: …

## 结构
- 层级：…
- 网格：页边 / 栏 / 对齐方式
- 模块顺序：…

## 样式令
- 字号层级：标题 / 小見出し / 正文 / 注释
- 色：主色 / 强调 / 文字 / 背景
- 间距刻度：组内 x / 组间 y / 页边 z

## 具体改动（若基于旧稿）
1. …
2. …

## 自检
- [ ] 余白  [ ] 揃える  [ ] グループ化  [ ] 強弱  [ ] 繰り返す
- [ ] 噪声已删  [ ] 对比足够
```

若直接改 HTML/CSS/组件：用同一套令（间距刻度、类型层级、色 token），避免页面级一次性魔数。

## 反模式

- 先挑字体配色，再想信息结构
- 用囲み代替分组
- 每页不同标题位置「求变化」
- 满版贴图当专业感
- 同时居中又左齐、对齐体系混用

## 边界

- 品牌手册优先；冲突时保留品牌，用五法则补齐结构
- 不编造数据或改业务结论，只改呈现
- 需要细审字体/图表细节时，可再叠加 typography / charts skill（若已安装）
