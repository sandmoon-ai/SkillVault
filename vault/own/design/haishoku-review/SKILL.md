# 配色审稿（配色设计原理）

审配色是否「对印象、有统一、能读清」。目标不是堆漂亮色票，而是指出观感偏差与可改方向。

规则来源：《配色设计原理》（日本奥博斯科编辑部）。只输出可验证问题与改法。

## 何时使用

- 审海报、杂志页、广告、包装、Web/UI 色板
- 用户说怪、脏、跳、花、廉价、不高级、不搭主题
- 需要先体检再改色

定印象 → `haishoku-impression`；建色板 → `haishoku-palette`；照片/双色 → `haishoku-photo`。

## 工作流

```
Review Progress:
- [ ] 1. 定目标印象、受众、媒介（屏/印）
- [ ] 2. 印象是否命中
- [ ] 3. 色调是否统一（明度×纯度基调）
- [ ] 4. 基本色是否匹配题材/行业
- [ ] 5. 多色：统一 vs 变化是否失控
- [ ] 6. 背景/文字/强调面积
- [ ] 7. 若有写真或限色：专项检查
- [ ] 8. 按严重度输出改色方向
```

## 1. 先对齐意图

写清：

- **目标印象**（1–3 词：清新 / 高档 / 活泼 / 沉着…）
- **受众与场景**
- **媒介**：RGB 屏 / CMYK 印 / 双色专色

无目标时，先根据题材推断「应有印象」，再审偏差。

## 2. 印象命中？

对照常见印象轴（详见 impression skill）：

| 观感风险 | 常见配色原因 |
|----------|----------------|
| 想高档却廉价 | 高纯多色乱战、金粉感乱加、对比脏 |
| 想清新却沉闷 | 色调过浊/过暗、冷暖混浊 |
| 想活泼却幼稚 | 高纯多色+甜美色相失控 |
| 想沉着却死气 | 明度过低且无强调节奏 |
| 想统一却花 | 色调不统一、色数过多 |

问：闭眼听目标词，睁眼看画面，是否同一件事？

## 3. 色调统一（本书核心）

**色调 = 明度 × 纯度的组合，最能左右整体印象。**

- 色相可以不同；**色调统一**仍可和谐
- 「说不出哪里怪」常是：各色分别处在鲜明/粉嫩/暗浊等不同色调带
- 审稿时把主色块标到色调带：是否落在同一带？强调色是否唯一出带？

例外：刻意对比表情时，变化应是**有设计的**（一处强调），不是满盘各调。

## 4. 基本色是否站得住

- 是否像该行业/品类该有的色（或有意反差）？
- 食物是否「可口」、健康是否「干净可信」、都市/自然是否方向对？
- 性别/年龄向若有诉求，是否误入儿童向或反之？

不匹配不一定错（可做差异化），但要能解释；解释不了 → 记问题。

## 5. 多色控制

- **统一向**：同/近色相，变化靠明度纯度
- **变化向**：互补/对比色相，但需压色数、统一色调或靠背景收
- 背景是否托住整页（白提亮热闹；黑托成人高档等——按目标选用）
- 文字色是否多彩到损可读、损统一？

## 6. 可读与面积

- 字与底对比是否够（尤其彩底、照片底）
- 强调色面积是否过大变吵、过小看不见
- 无彩色（黑白灰）是否用来缓冲冲突？该用却没用？

## 7. 写真 / 双色（若存在）

- 配色是否抢照片？
- 照片色是否与基本色打架？
- 双色是否「为限色而脏」或毫无目的？

细则转 `haishoku-photo`。

## 理论不适用时

下列情况放宽教条，改看「目的是否达成」：

- 品牌手册强制色
- 摄影/插画本身已是多色主体，版面只做配角
- 刻意冲突的艺术向（需声明）
- 无障碍对比法规优先于印象美学

在报告里标注：**品牌/法规优先** 或 **有意破例**。

## 输出格式

```markdown
# 配色 Review

**目标印象**: …
**媒介**: …
**总判**: [1–2 句：最大问题是印象偏差 / 色调分裂 / 色数失控 / …]

## 色角色（现状）
| 角色 | 色（描述或值） | 色调带 | 问题 |
|------|----------------|--------|------|
| 背景 | | | |
| 基本色 | | | |
| 辅助 | | | |
| 强调 | | | |
| 文字 | | | |

## 问题清单

### 🔴 Critical
1. **[现象]** → 违反：色调统一 / 印象 / 可读…
   - 改法：…（保什么、改什么、建议色调方向）

### 🟡 Should fix
…

### 🟢 Nice to have
…

## 建议改色顺序
1. 锁定目标印象与色调带
2. 收基本色与背景
3. 再处理多色与强调
4. 最后校文字可读
```

规则：

- 少说「更高级一点」；要说「降纯度并统一到暗浊色调」这类可执行方向
- 能给色值更好；不能则给色相+色调带+角色
- 一次报告优先修 Top 问题，避免重做整本色谱

## 反模式

- 只推「流行色」不谈印象与色调
- 每个元素换一个高纯色「丰富画面」
- 用渐变/光效掩盖色调分裂
- 忽略印刷/屏幕色域差异却给死色值（不确定时标注「需打样/校准」）

## 边界

- 不替代品牌 VI；冲突时标注
- 与 `tsutawaru-layout`：那边保信息清晰少噪声；这边保印象与色调策略
- 与 `krug-*`：对比可读可叠；导航认知不归本 skill
