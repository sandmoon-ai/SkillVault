# 伝わるデザイン Typography

处理字体选择与文字組。目标：判读性与层级清楚，不为「个性」牺牲阅读。

## 何时使用

- 选字体、统一和欧混排、调整标题/正文层级
- 用户说字难看、读不动、行距怪、列表乱
- Layout 已定，需要落到具体文字样式令

## 工作流

```
Typography Progress:
- [ ] 1. 定场景：読ませる vs 見せる；屏 vs 印
- [ ] 2. 选字体家族（正文 + 标题，尽量克制）
- [ ] 3. 定字号/字重层级（3–4 级）
- [ ] 4. 调行間・字間・行长・对齐
- [ ] 5. 处理好列表、数字、约物、混排
- [ ] 6. 去掉变形与过度装饰
```

## 书体选择

### 总原则

- **避免花哨/手写/过度设计字体**做正文或长标题
- 一套资料：**正文 1 种 + 标题同族或可混用的 1 种**，不要字体展览
- 屏显优先清晰轮廓；避免粗糙旧ゴシック作为正文主力（如过时的 MS Pゴシック观感）
- 品牌指定字体优先；无指定时选高判读性、常见可嵌入/可替代字体

### 読ませる（长文、説明）vs 見せる（标题、短句）

| 用途 | 要点 |
|------|------|
| 読ませる | 稳定、字面清晰、长时间阅读不累；层级靠字号字重，不靠花体 |
| 見せる | 可稍强个性，但仍要远距离可辨；避免扭曲、空心堆特效 |

### 混排

- 和文/中文用和文字体；拉丁与数字尽量用匹配的欧文或同族拉丁轴
- 混排时检查：字重是否一头重一头轻、基线是否跳、拉丁是否过大
- 全角/半角约物按场景统一，不要同页混用多种「看起来像逗号」的符号

### 推荐方向（无品牌约束时）

Windows / Office 常见可用方向（按环境取舍）：

- 和文屏显：游ゴシック / メイリオ 等清晰ゴシック系
- 欧文/数字：与和文和谐的无衬线（如 Segoe UI、Arial 等，视平台）
- 长文印刷：可考虑明朝系正文（若整体风格与可读性允许）

不要把「推荐」写成必须；以判读性与统一性为准。

## 字号・字重・强调

建立 **3–4 级** 即可：

| 级 | 角色 | 手段 |
|----|------|------|
| 1 | 主标题 | 更大 + 可加粗 |
| 2 | 小見出し | 中号 + 稍重或主色 |
| 3 | 正文 | 稳定字号、常规字重 |
| 4 | 注释/来源 | 更小或灰色（对比仍够） |

约束：

- **跳率要够**：标题与正文不能只差一点点
- **粗体**：用于结构强调，不整段加粗
- **斜体**：和文慎用；拉丁短词可，不靠斜体做主层级
- **数字强调**：关键数字可更大；单位/说明更小，形成「数大单位小」

## 文字組

### 对齐

- 正文默认 **左揃え**
- 和文长文慎用两端揃え（易出齿缝）；需要整齐时优先调栏宽与字号
- 居中只给短标题/少数展示句，不给长段

### 行間・字間・行长

- 行間随行长增加略增；过紧像墙，过松像散沙
- Office 注意：部分行距设定偏欧文习惯，和文要目视校准
- 字間：正文保持默认或微松；标题可微收，但勿挤成一块
- **行长别太长**：一行字数过多则难扫读 → 缩栏、段组、或拆块

### 段落与换行

- 用段落样式/段间距表达结构，少靠连续空行
- 换行避开「助词落单」、语义切断；标题尽量在语义边界断行
- インデント：不是默认必需；层级清楚时可用段距+見出し代替深层缩进

### 箇条書き

- 一项一事；符号全篇统一
- 多级列表层级视觉差明确（缩进 + 符号/字号）
- 列表与正文共享左缘体系，不要另起一套随机缩进
- 小見出し与其后的列表要成组（近、齐、段距稳定）

## 禁止与慎用

- 水平/垂直拉伸变形文字
- 厚描边、强烈阴影、彩虹字、空心+阴影叠buff
- 正文旋转扭曲
- 每页换一套字体「增加趣味」
- 浅灰小字印在浅底或照片上

## 样式令输出模板

```markdown
# Typography 令

**场景**: [スライド/文書/…] [屏/印]
**字体**:
- 标题: …
- 正文: …
- 拉丁/数字: …

**层级**:
- H1: …px/pt, weight …
- H2: …
- Body: …
- Caption: …

**組版**:
- 对齐: 左揃え（例外: …）
- 行間: …
- 行长策略: …
- 列表: 符号… / 缩进…

**混排与数字**:
- …
```

若直接改 CSS/组件：映射为 token（`--font-sans`、`--text-lg`、`--leading-body`），避免散落魔法数。

## 与 Layout 的衔接

- 字号层级服务 Layout 的「強弱」
- 左縁对齐服务「揃える」
- 段距/列表成组服务「グループ化」
- 全篇样式锁定服务「繰り返す」

冲突时：先保层级与对齐，再谈字体个性。

## 边界

- 不替换用户明确指定的品牌字体；只校准层级与組版
- 无障碍/UD：优先对比与字形清晰，胜于装饰
- 深度图表规则交给 `tsutawaru-charts`；整页结构交给 `tsutawaru-layout`
