# 写真配色与双色（配色设计原理 Ch4–5）

照片是主角时，版面色服务影像；双色是限色策略，不是随便少两管颜料。

## 何时使用

- 杂志/宣传页大面积写真、电商主图页、英雄图落地页
- 黑白照片配色、照片上压字
- 双色印刷、双色视觉风格、duotone 海报

无照片的普通 UI 色板 → `haishoku-palette`。先定印象 → `haishoku-impression`。

## 工作流

```
Photo/Duotone Progress:
- [ ] 1. 定照片角色：英雄 / 配图 / 背景纹理
- [ ] 2. 从照片抽取或回避的色（服务影像）
- [ ] 3. 选基本色与背景，使照片更显
- [ ] 4. 定照片上文字与控件色（可读）
- [ ] 5. 若双色：定目的 → 选两色 → 分配层次
- [ ] 6. 自检：是否抢戏、是否脏、是否可读
```

## 写真版面：基本法则

1. **照片优先** — 版面色不与照片抢主叙事  
2. **基本色从照片关系来** — 吸取照片主色做和谐，或取对照色做有控对比  
3. **色调跟随照片情绪** — 明亮通透的片配浊色底会「坠」；暗调片配糖果色易违和  
4. **多色综合运用时仍要有锚** — 基本色重复出现，照片才像同一辑  

### 搭配写真的基本色

| 策略 | 做法 | 适用 |
|------|------|------|
| 和谐吸取 | 基本色取自照片主色相，降纯作版面色 | 时尚、旅行、品牌故事 |
| 中性托底 | 大面积黑/白/灰，让照片自带色彩 | 摄影作品集、高档 |
| 有控对比 | 小面积对比色强调 CTA/标题 | 需要行动转化时 |

避免：版面再铺一套与照片无关的高纯多色「第二彩虹」。

### 为展现写真而综合用色

- 周围色块面积、纯度低于照片主体区域  
- 分隔线、标签用低刺激色  
- 需要多彩点缀时：从照片里「借色」，并统一色调带  

### 黑白写真

- 版面可引入 **一个** 有彩色强调，或保持全无彩更纯  
- 慎用多鲜色边框把 B&W 变成贴纸墙  
- 灰阶照片的明度结构 = 你的层级参考（标题落在哪里更清楚）

## 写真上的文字色

优先级：

1. **对比可读**（含移动端缩小后）  
2. 不破坏脸/主体关键区  
3. 贴近印象令  

手法：

- 字色取照片暗部/亮部的反差侧  
- 必要时：半透明底、色带、渐变蒙皮（克制）  
- 长文不要直接铺在忙乱照片上 → 改侧栏或下方纯色区  
- 描边/阴影只作可读急救，不作风格主菜  

## 双色选择（Ch5）

双色 = **有目的的限色**，常见目的：

- 印刷成本/工艺（双色印刷）  
- 强烈识别与冲击  
- 统一系列感  
- 用两色「翻译」四色写真的情绪  

### 流程

1. **写目的**：省钱 / 冲击 / 品牌两色 / 复古印刷感…  
2. **选主色 + 辅色**：通常一色承托（深/中性），一色叙事（品牌或强调）  
3. **分配**：大面积给承托色；小面积给冲击色；照片作双色/duotone 时保持层次  
4. **测试**：小字可读、图标可辨、照片主体仍可分离  

### 用双色表现「像四色」的层次

- 靠明度阶（同一色的深浅）模拟层次，而不是偷偷加第三有彩色  
- 照片转双色：保留明暗结构，再映射到双色曲线  
- 需要第三色时：优先用纸白/黑当「第三无彩」，仍算双色策略干净  

### 有针对性的双色

| 目的 | 倾向 |
|------|------|
| 强冲击 | 高对比对（如深底+高纯强调） |
| 高档克制 | 黑/深海军 + 一金属感或低纯强调（慎闪金） |
| 清新 | 浅底 + 一冷色主调 |
| 促销热闹 | 两高刺激色需靠面积一主一辅，避免均势互殴 |

## 若双色
- 目的: …

## 自检
- [ ] 不抢照片
- [ ] 字可读

## 理论不适用时

- 照片只是纹理且可裁切重染：可按普通 palette 处理  
- 品牌双色强制：照片处理服从品牌，可读不够时加蒙皮而非加第三品牌色  
- Web 英雄图：注意压缩与对比；暗图上的字按 UI 对比标准验收  

## 反模式

- 照片四周一圈彩虹标签  
- 双色名义下实际五色渐变  
- 脸/商品上叠低对比花字  
- 忽略印刷套准/纸色，却按屏幕荧光双色交货  

## 边界

- 不替摄影指导布光；只管版面色与照片的关系  
- 侵权/肖像/商标色不在范围  
- 总审：`haishoku-review`；无图色板：`haishoku-palette`
