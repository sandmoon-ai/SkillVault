# レイアウトの基本（揃える）

在目的已定后做配置设计。本书抓手：**レイアウトの基本は「揃える」**；余白与グループ化服务信息，不是填满或摆酷。

前置：最好有 `nyumon-purpose` 目的令。无目的先回去定目的。

## 何时使用

- 排チラシ、スライド、企画ページ、通知
- 元素歪、挤、散、没有主次
- Review 指向布局层问题

与 `tsutawaru-layout`：可叠用；本 skill 跟入门教室词汇（グリッド/版面角色），伝わる五法则细节可互参。

## 工作流

```
Layout Progress:
- [ ] 1. 读目的令：主信息、必现模块、力度
- [ ] 2. 定版心与マージン
- [ ] 3. 定グリッド / 对齐体系
- [ ] 4. 分配角色区（标题/主视觉/本文/CTA…）
- [ ] 5. グループ化 → 揃える → 余白
- [ ] 6. 強弱（尺寸・粗细・位置・对比）
- [ ] 7. あしらい克制检查
```

## 基础规则

### 1. 揃える

- 选主对齐线（常左缘或栏网格）并贯彻  
- 多对象：左齐/上齐/中线一致，禁止「差不多」  
- 图标+文字：图标盒宽统一，字左缘齐  

### 2. マージン与版心

- 四边留足页边；内容勿贴物理边  
- 版心内再分栏；栏间距稳定  
- 满版出血图可以，但文字安全区仍要守  

### 3. グリッド

- 用简单网格决定「能放哪」  
- 卡片/栏目宽度成比例，不随意三种宽  
- 跨页/多页资料：网格与页眉区重复（安定感）  

### 4. グループ化

- 相关靠近、无关拉开（组内紧、组间松）  
- 标题贴所属内容  
- 图与说明成组  

### 5. 強弱

用目的定的优先级驱动：

| 级 | 手段 |
|----|------|
| 主信息 | 更大/更重/更上位/更高对比 |
| 支持信息 | 中等 |
| 元数据 | 小、弱、边角 |

跳率要够；到处强调 = 没有强调。

### 6. 余白

- 问「余白留在哪」与「物件放哪」同等重要  
- 余白区分区块、呼吸、高级感（按目的）  
- 怕空就塞装饰 → 通常变业余  

### 7. あしらい（点缀）

- 线、色块、图标、底纹只服务结构或目的语气  
- 能删则删；不能删则统一风格与线宽  
- 禁止用装饰掩盖对齐失败  

## 按文类的速配

**チラシ：** 主句 → 关键信息 → 次要 → CTA；远看主句成立。  
**スライド：** 一页一意；标题区锁定；页边统一。  
**企画/文書：** 見出し带稳定；两栏时对齐线贯穿。

## 改乱稿顺序

1. 删无效あしらい  
2. 按目的砍/降级模块  
3. 重设页边与一列对齐  
4. 重组グループ与间距刻度  
5. 重建強弱  
6. 最后微调  

## 反模式

- 居中+左齐混用无体系  
- 用大色块框代替分组  
- 每页重发明标题位置  
- 把「密」当成「信息量大」  

## 边界

- 不选具体字体色值（交 elements / haishoku）  
- 品牌模板优先，在其内做揃え与余白  
- 深伝わる规则可叠 `tsutawaru-layout`
