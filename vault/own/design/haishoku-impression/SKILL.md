# 整体配色与印象（配色设计原理 Ch1）

先定「给人什么感觉」，再用**色调统一**锁住整页气质。色相是表情细节；色调是整脸轮廓。

## 何时使用

- 项目起步：还没有色板，只有「要清新/要高档/要热闹」
- 现有稿「说不出的怪」——先校准印象与色调带
- Review 结论指向印象偏差，需要重定调

落地选色与多色结构 → `haishoku-palette`。

## 工作流

```
Impression Progress:
- [ ] 1. 写目标印象词（1–3 个）与反义词（不要什么）
- [ ] 2. 选主色调带（鲜明 / 明亮 / 浅淡 / 浊 / 暗…）
- [ ] 3. 定冷暖与力度（强/弱、轻/重）
- [ ] 4. 映射到印象轴（见下表）
- [ ] 5. 规定：统一色调；谁可以出带（通常仅强调色）
- [ ] 6. 输出印象令（供 palette 执行）
```

## 核心法则：色调决定整体

- **色调** = 明度与纯度的组合 → 决定基调与氛围
- 同一色相在鲜明、明亮、暗浊等色调中表情完全不同
- **无论色相如何，色调统一 → 易得和谐、整体感**
- 先选色调带，再在带内选色相；不要先捡一堆漂亮色再事后调和

## 印象轴（选型地图）

按目标勾选主轴，并写出「要 / 不要」：

| 印象方向 | 色调/策略倾向（概括） | 慎用 |
|----------|----------------------|------|
| 暖意、活跃 | 暖色相 + 较高活力色调；明快对比 | 大面积冷浊压活力 |
| 寒冷、镇静、清凉 | 冷色相 + 冷静色调；可偏低纯 | 高纯暖色大面积 |
| 成人 | 低纯/暗调、克制色数；黑灰托 | 高纯多色糖果感 |
| 儿童 | 明亮、较高纯、友善色相；色数可稍多但要有主色 | 暗浊压抑 |
| 国家/地域/文化 | 联想到符号色与习惯色（研究后用，避免刻板冒犯） | 随意「民族风」拼盘 |
| 华丽、快乐 | 较高纯、明度节奏强；白底可抬热闹 | 全暗无高光 |
| 沉着、安逸 | 中低纯、柔和对比、邻近色 | 强互补乱闪 |
| 流行、繁华 | 时感色相+清晰对比；仍需主色 | 过时脏灰却自称潮 |
| 清新、爽快 | 高明、偏冷或嫩绿系、留白感 | 浊褐厚重 |
| 高档 | 少色、低纯或深色调、黑/金须克制 | 高纯五色齐飞 |
| 价廉/亲和促销 | 高纯、强对比、醒目强调（有意为之） | 与「高档」目标混用 |

印象词要具体：「高级」→ 再拆成冷金/墨色极简，还是暖奶油轻奢？

## 定调步骤（实操）

1. **一句话场景**：谁、在哪、看什么媒介、要信什么  
2. **印象词**：正 1–3 + 负 1–2（「不要幼稚」「不要阴暗」）  
3. **主色调带**：只选一个主带（90% 面积落在此）  
4. **冷暖**：偏暖 / 偏冷 / 中性  
5. **力度**：强冲击 / 中 / 柔和  
6. **出带许可**：强调色可否更高纯/更对比？面积上限？  
7. **无彩色策略**：白抬明亮热闹；黑托成人高档；灰作缓冲  

## 理论不适用时

- 客户指定「必须五彩」：用**统一色调**消化多色，而不是放弃印象  
- 摄影已决定情绪：版面色调追随照片，不另起炉灶  
- 无障碍强制高对比：在对比达标前提下，尽量靠近目标色调带  

## 输出格式

```markdown
# 印象 / 色调令

**场景**: …
**目标印象**: …（不要: …）

## 色调策略
- 主色调带: …
- 冷暖: …
- 力度: …
- 面积规则: 主调 ≥ …%；强调出带 ≤ …%

## 无彩色
- 背景倾向: 白 / 灰 / 黑 / 浅彩
- 作用: …

## 色相方向（尚未定死色值）
- 主色相候选: …
- 辅助: …
- 强调: …
- 禁用色相/印象: …

## 成功标准
- 3 秒观感应是: …
- 失败信号: …
```

交给 `haishoku-palette` 时：本令优先于「好看的零散色票」。

## 反模式

- 先从流行色网站拖五色再找故事
- 每个板块换一种印象（首页清新、内页土豪）
- 用「高级灰」当万能词却仍高纯乱跳
- 文化符号色不经核实直接用

## 边界

- 不输出完整 VI 手册；只锁定本项目/本页印象
- 品牌已有色：在品牌色上调**色调与面积**，而不是擅自换色相（除非授权）
