# デザイン要素（写真・文字・図解）

目的与布局骨架已定后，配置要素：写真、书体、文章块、图解/表/グラフ；配色只定方向，深配色走 `haishoku-*`。

前置：`nyumon-purpose` + 最好已有 `nyumon-layout` 区域角色。

## 何时使用

- 选图/裁图、定标题字体、排长文、做流程/表/グラフ
- 图文打架、字难看、信息该图解却仍是墙文
- Review 指向要素层

## 工作流

```
Elements Progress:
- [ ] 1. 按区域角色列出所需要素
- [ ] 2. 写真/画像（Ch3）
- [ ] 3. 配色方向（Ch4 轻量）→ 需要时转 haishoku
- [ ] 4. 文字と书体（Ch5）
- [ ] 5. 文章のデザイン（Ch6）
- [ ] 6. インフォグラフィック（Ch7）
- [ ] 7. 与布局令对齐自检
```

## Ch3 写真と画像

按目的选，不按「好看图库」。

| 角色 | 要点 |
|------|------|
| 主视觉 | 情绪/主题一眼可感；主体清晰 |
| 证据图 | 真实、可辨细节；少滤镜喧宾 |
| 背景 | 降对比或虚化，保证字可读 |
| 图标/插图 | 风格统一、线宽一致 |

做法：

- 裁切服务主体与视线；勿切脸/商品关键部  
- 方向与栏宽匹配；少无意义变形  
- 图注/来源用弱层级，贴图成组  
- 无合适图时：宁可纯色+排版，不要烂图凑数  

## Ch4 配色（轻量桥接）

在本 skill 只输出：

- 印象方向词（清爽/信赖/活力…）  
- 色数上限与对比底线（字必须可读）  
- 「战略用色」：色服务目的情绪，不是装饰填空  

完整色板/色调统一 → `haishoku-impression` / `haishoku-palette`。  
写真页抢色 → `haishoku-photo`。

## Ch5 文字と书体

- 书体印象贴目的（严谨/亲切/促销）  
- 一套资料：标题与正文克制混用，勿字体展览  
- 屏显优先判读性；印刷注意字号与纸性  
- 强调靠层级，不靠花式变形字  
- 和欧混排时检查字重与气质是否脱节  

细組版可叠 `tsutawaru-typography`。

## Ch6 文章のデザイン

让文字块可被扫读与精读：

- 見出し层级稳定（视觉差够）  
- 短段、列表、一行长度可控  
- 段落间距统一；少空行硬堆结构  
- 引文/注记弱化但不低于可读对比  
- 长文：导航靠見出し，不靠花边框  

文案内容结构（消息/读者）可叠 `kaku-design`；此处管**呈现**。

## Ch7 インフォグラフィック

复杂信息优先图式化。

| 目的 | 形式 |
|------|------|
| 步骤/流程 | 番号ステップ、简箭头 |
| 比较 | 表或棒 |
| 构成 | 慎用円；表/棒常更清晰 |
| 关系 | 简洁ボックス+線 |
| 精确数值 | 表 |

规则：

- 一图一读法；去 3D/阴影/渐变垃圾  
- 标题尽量是结论或清晰问题  
- 表：少线、数右文左、单元格有余白  
- 与正文共享对齐与色（强调色唯一）  

细规则可叠 `tsutawaru-charts` / `haishoku-photo`（若图是照片）。

## 输出格式

```markdown
# 要素令

**目的摘要**: …
**布局区域**: …

## 写真/画像
- 角色: …
- 选图标准: …
- 裁切/处理: …
- 不用: …

## 配色方向（轻）
- 印象: …
- 色数上限: …
- 深做: haishoku-…（若需要）

## 书体
- 标题: …
- 正文: …
- 层级字号: …

## 文章块
- 見出し策略: …
- 段/列表: …
- 行长/栏: …

## 図解/表/グラフ
- 需要图式化的信息: …
- 形式: …
- 样式约束: 无立体影渐变；对齐…

## 自检
- [ ] 图服务目的且不抢字
- [ ] 字层级可读
- [ ] 该图解处已图解
- [ ] 色未失控
```

## 反模式

- 图库风与目的无关的假笑商务图  
- 每级标题换一种装饰字体  
- 用彩色大表代替一句结论  
- 配色先彩虹，再补故事  

## 边界

- 不替代摄影/插画创作本身  
- 数据真实性不编造  
- 总审：`nyumon-review`；骨架：`nyumon-layout`；目的：`nyumon-purpose`
