# 基本色与多色配色（配色设计原理 Ch2–3）

把印象令落成可执行色板：基本色 → 背景 → 辅助/强调 → 文字。多色时先选「统一」还是「变化」。

## 何时使用

- 已有目标印象/色调带，需要具体色角色与色值
- 版面颜色多、花、打架，需要结构
- 按行业/受众/季节选主色

未定印象时先跑 `haishoku-impression`。照片主导版面 → 叠加 `haishoku-photo`。

## 工作流

```
Palette Progress:
- [ ] 1. 读入印象令（色调带、冷暖、力度）
- [ ] 2. 选基本色（题材匹配）
- [ ] 3. 选多色策略：统一 or 变化
- [ ] 4. 定背景色（定整页气质）
- [ ] 5. 定辅助、强调、文字
- [ ] 6. 控色数与面积
- [ ] 7. 输出色板令（角色+值+用途）
```

## 选择基本色（Ch2）

基本色 = 决定「这是谁的设计」的主色锚点。

选型维度（按项目勾选）：

| 维度 | 问题 | 选型提示 |
|------|------|----------|
| 行业/品类 | 像不像这个行业？ | 匹配习惯色，或有意反差并解释 |
| 食物 | 是否显得可口？ | 暖、新鲜、避免脏浊绿褐乱撞 |
| 男性向/女性向 | 受众是否贴切？ | 避免刻板的同时尊重品类预期 |
| 季节 | 春夏秋冬？ | 冷暖与明度跟随季节空气感 |
| 都市 / 自然 | 混凝土还是草木？ | 冷灰金属 vs 绿土植物调 |
| 健康 | 是否干净可信？ | 清爽、低脏感、充足「空气」 |

规则：

- 基本色落在印象令的**主色调带**内
- 基本色应能重复出现（栏目色、标题色、键色）形成记忆
- 不要让辅助色比基本色更抢戏（除非叙事需要）

## 多色策略（Ch3）

### A. 统一性配色（同/近色相）

- 色相相同或邻近，靠明度/纯度造层次
- 适合：高档、沉着、品牌识别强、长文档
- 风险：单调 → 用强调色小面积出带

### B. 变化性配色（互补/对比色相）

- 用对比制造活力、快乐、冲击
- 必须：**限色数** + **尽量统一色调** + **背景收口**
- 风险：花、廉价、儿童向误触

### 色调调节 = 表情

同一组色相，把色调拧到鲜明/浅淡/暗浊，整页表情会变。改稿时优先拧色调，再改色相。

## 背景色（左右整页风格）

| 背景倾向 | 常见效果 |
|----------|----------|
| 白 / 近白 | 抬明度、衬鲜色、热闹/清爽易出 |
| 浅灰 / 浅彩 | 柔和、减对比刺激 |
| 黑 / 深色 | 成人、高档、让鲜色更跳（控面积） |
| 强彩底 | 冲击大；文字与组件对比难，慎用 |

多色场面：白可缓冲突；黑可托高档——按印象令选，不要默认。

## 文字色与强调

**文字：**

- 可读第一：深字浅底或反白须够对比
- 多色文字可造表情，但标题体系要稳定；正文少换色
- 彩底/复杂底上的字：加底托、描边慎用、优先换底或换字色

**强调色：**

- 一页通常 **一个** 主强调叙事
- 面积小、纯度可高于主色调带（出带许可内）
- 用于 CTA、关键数字、关键标签——不是每条线都强调

**无彩色：**

- 白/灰/黑缓冲有彩色冲突、稳定结构
- 灰字注意对比；别用浅灰字+浅底冒充高级

## 色数与面积

- 有彩色角色宜少：基本 + 辅助(0–2) + 强调(0–1)
- 组内紧、强调稀；大面积给低刺激色，小面积给高刺激色
- 重复用色：同一语义反复同一色（链接色、错误色、品牌色）

## 输出格式

```markdown
# 色板令

**印象摘要**: …
**策略**: 统一近色 / 对比变化
**色调带**: …

## Roles
| 角色 | 色值 | 色相/色调 | 用途 | 面积 |
|------|------|-----------|------|------|
| Background | | | | 大 |
| Primary (基本色) | | | | 中 |
| Secondary | | | | 小–中 |
| Accent | | | | 小 |
| Text | | | | — |
| Muted / Border | | | | — |

## 规则
- 强调出带: 允许/禁止；上限 …
- 禁止: …
- 屏幕/印刷备注: …

## 应用示例
- 标题: …
- CTA: …
- 卡片/区块: …
```

落代码时映射 token：`--color-bg`、`--color-primary`、`--color-accent`、`--color-text`，避免裸十六进制散落。

## 理论不适用时

- VI 锁定：只调面积与中性色，不动品牌主色相
- 数据可视化：类别色要可辨，可放宽「少色」，但仍尽量靠近主色调带
- 无障碍：对比不达标时，优先提对比，再回调印象

## 反模式

- 彩虹导航、每块一色
- 基本色与强调色纯度面积双高
- 互补色大面积对撞无灰/无白缓冲
- 背景强彩 + 多色字 + 多色图标同时出现

## 边界

- 不保证印刷色差；CMYK/专色需打样时标明
- 与 `tsutawaru-layout` 叠用：那边管少噪声与层级；这边管色角色
- 审稿总入口：`haishoku-review`
