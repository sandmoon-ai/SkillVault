# Krug Navigation & Homepage（街头指示牌）

做导航与首页：让人知道「有什么、在哪、怎么走」，像街上的路牌，不像迷宫彩蛋。

## 何时使用

- 设计/重做顶栏、菜单、信息架构、面包屑、搜索入口
- 首页说不清「这是干什么的」
- Trunk Test 失败后的结构修复

文案扫描细改 → `krug-scan`；只体检 → `krug-review`。

## 工作流

```
Nav Progress:
- [ ] 1. 列出用户任务与内容库存
- [ ] 2. 定持久导航元素（每页重复）
- [ ] 3. 定栏目名（清晰、互斥、用户语言）
- [ ] 4. 当前位置 + 面包屑 + 页名
- [ ] 5. 搜索与工具区
- [ ] 6. 首页大爆炸：3–4 秒内讲清大局
- [ ] 7. 移动：裁剪与抽屉策略
- [ ] 8. 用 Trunk Test 自检
```

## 导航为何重要

导航不只是控件，它：

1. 告诉用户 **怎么用这个站**
2. 揭示 **这里有什么**
3. 建立 **可信与掌控感**

迷路时，用户怪自己或直接离开——很少读帮助。

## 持久导航（Persistent Navigation）

除少数例外（如专注表单、全屏流程），大多数页应稳定出现：

| 元素 | 作用 | 要点 |
|------|------|------|
| 站点 ID（Logo/名） | 这是谁 | 通常左上；可回首页 |
| 主导航栏目 | 主要分区 | 少而清；当前项高亮 |
| 工具链接 | 账户/帮助/购物车等 | 与内容栏目区分开 |
| 搜索 | 带着意图直达 | 标签用「搜索」；简单输入+提交 |
| 页面名称 | 我在哪一页 | 显眼；与点击来源文案一致 |
| 当前位置指示 | 我在结构何处 | 导航高亮；深层级加面包屑 |
| 局部导航 | 本节还有什么 | 与全局栏目区分层级 |

例外：结账/注册等关键路径可收导航，但要有 **退出/返回** 与进度感，勿把人关进黑屋。

## 命名与结构

- 栏目名用 **用户任务语言**，少用内部组织名
- 互斥、同级平行；避免「产品 / 解决方案 / 生态」三重叠
- 「你在这里」必须可见——别靠用户记点过哪
- 面包屑：深层级有用；从高到低；当前页可纯文本
- 页名 ≠ 营销口号；页名要像路牌

## 搜索

- 需要搜索的站：入口可见，不要藏三重菜单
- 控件文案就是「搜索/Search」，别叫「探索宇宙」
- 首页与内页行为一致；结果页仍能继续导航

## 首页：大爆炸理论

用户落地后极短时间要建立心智模型。首页应尽快回答：

1. **这是什么？**
2. **这里有什么？**
3. **我能在这做什么？**
4. **为什么留下来 / 信任你？**

设计要点：

- 一句清晰价值主张（可配短 tagline；tagline 要说明而非空喊酷）
- 主导航与搜索可见
- 主路径 CTA 明确（开始用 / 看定价 / 找内容…按产品）
- 及时内容、促销、入口捷径可以有，但 **不能压过身份与主路径**
- 承认首页「谁都想加一块」——用优先级裁剪，不靠堆

自检：遮住品牌名，只看首屏文案与导航，陌生人能否说出你是干什么的？

## 移动导航

- **先裁剪再折叠**：塞进汉堡菜单不等于解决优先级
- 主任务入口尽量外露；次要进菜单
- 菜单打开后仍要能回答 Trunk 问题（这是谁、有哪些部）
- 触控：条目高度与间距够用；避免桌面悬停才出现的关键操作
- 首页移动首屏：身份 + 主 CTA + 进入内容的线索

## Trunk Test 验收

任意内页：

- [ ] 什么站？
- [ ] 哪一页？（页名正确且显眼）
- [ ] 主栏目？
- [ ] 本区选项？
- [ ] 我在哪（高亮/面包屑）？
- [ ] 怎么搜（若需要）？

首页额外：

- [ ] 3–4 秒内说清是什么、能做什么
- [ ] 主 CTA 唯一主音量

## 输出格式

```markdown
# Navigation / Homepage 方案

**产品一句话**: …
**核心任务**: 1.… 2.…

## IA 栏目
| 栏目 | 用户任务 | 子项 |
|------|----------|------|
| | | |

## 持久导航令
- Logo/回首页: …
- 主栏目: …
- 工具区: …
- 搜索: …
- 页名规则: …
- 当前位置: …
- 面包屑: [要/不要及层级]

## 首页首屏
- 主张: …
- 主 CTA: …
- 次要入口: …
- 弱化/不放首屏: …

## 移动策略
- 外露: …
- 进菜单: …

## Trunk 自检结果
…
```

## 反模式

- 创意导航名让人猜
- 每页导航结构漂移（破坏「反复」信任）
- 首页轮播五屏才说出是干什么的
- 用mega菜单堆几百链接代替信息架构决策
- 移动端只做汉堡，首屏没有主任务

## 边界

- 不重写业务战略；IA 冲突时标出需产品决策的取舍
- 视觉样式可叠 `tsutawaru-layout`；可用性摩擦总审用 `krug-review`
