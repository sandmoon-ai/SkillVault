# 伝える力 — 句级改写对照

供改稿时查阅。原则优先于文采。

## 结论位置

| 弱 | 强 |
|----|----|
| 关于本次预算调整，各部门讨论后认为……（最后才说砍什么） | 建议先砍广告预算 15%，以保住研发编制。理由如下。 |
| 本文将探讨客户流失的多种原因 | 客户流失主因是续费提醒太晚，不是价格本身 |

## 术语噛み砕く

| 弱 | 强 |
|----|----|
| 我们要做一次全链路的数字化转型 | 我们要把下单→发货→开票这几步都改成系统自动完成（数字化转型） |
| 提升用户心智份额 | 让更多目标客户一想到这类产品就先想到我们 |
| 沉淀组织能力 | 把这次做法写成可复用的清单，让新人不用靠老人带也能做 |

## 抽象 → 具体

| 弱 | 强 |
|----|----|
| 最近业绩不太好 | 7–8 月新签比去年同期少 22% |
| 相关方需尽快协同 | 销售与交付需在本周五前对齐全量未结案客户名单 |
| 适当优化流程 | 把审批从 4 级减到 2 级：经理 → 财务 |

## たとえ（类比）

用法：先结论 → 「打个比方」→ 点明相似点 → 回到本题。

- 好：相似点单一、对方生活里真有的事  
- 坏：类比比本题更难，或暗示错误机制  

## 事実 vs 意見

| 缠在一起 | 分开 |
|----------|------|
| 这个方案肯定能提升转化 | **事实**：A/B 测试里新文案转化 3.1%→4.0%。**意见**：我认为可以全量上线。 |
| 市场都在往这个方向走 | **事实**：头部三家里有两家已上线同类功能。**意见**：我们若 Q4 不做，可能丢标杆客户。 |

## 主語と文の長さ

| 弱 | 强 |
|----|----|
| 在推进相关举措的过程中，被指出存在需改善之处 | 客户指出：账单页看不懂套餐差异 |
| 关于是否实施，取决于多方面因素的综合考量 | 是否上线，取决于两件事：成本是否低于 20 万，以及客服是否能在上线前完成培训 |

拆句规则：出现「的过程中 / 方面 / 相关 / 进行」堆叠时，多半该拆。

## 口头 30 秒版模板

```
一句话结论。
这对你意味着：…。
举个例子：…。
若你只记一件事：…。
```

## 讲解分层（同一话题）

1. **街坊版**（零术语）  
2. **同事版**（必要术语 + 定义）  
3. **专家版**（机制、边界、例外）  

默认从 1 起；对方跟得上再进 2/3，勿一上来专家版。
