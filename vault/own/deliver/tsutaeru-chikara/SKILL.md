# 伝える力（池上彰）

目标：**让对方明白**，不是证明你懂很多。专业度用准确与具体体现，不用术语堆砌体现。

规则来源：池上彰『伝える力』的可执行要点。只产出可改结构与措辞，不写「更有感染力」这类空话。

与相邻 skill 分工：

| 需求 | 交给 |
|------|------|
| 逻辑塔 / 结论统下 | `minto-pyramid` |
| 成文流程（设计→草稿→推敲） | `kaku-*` |
| 版式・图表「看起来伝わる」 | `tsutawaru-*`（別书『伝わるデザインの基本』） |
| **说明・讲解・口语化・去行话** | **本 skill** |

## 何时使用

- 把专业内容讲给非专家、领导、客户、新人
- 用户说「太难懂 / 全是术语 / 听完不知道重点」
- 写说明文、FAQ、演讲稿、汇报开场、产品解释、新闻式解说
- 审一版文字：信息在，但「伝わらない」

## 工作流

```
Tsutaeru Progress:
- [ ] 1. 定相手（知识、关心点、要他做什么）
- [ ] 2. 写一句「听完/读完应留下的话」
- [ ] 3. 结论先行，再理由/背景/例子
- [ ] 4. 术语全部翻译或举例落地
- [ ] 5. 事实与意见分开；补具体（数字・固有名词）
- [ ] 6. 短句・主語清楚・一段一意
- [ ] 7. 自检三问后输出
```

## 核心原则（按优先级）

### 1. 相手の頭で考える

动笔/开口前先写清：

1. **相手是谁**（角色 + 大概知识水平）
2. **他已经知道什么 / 不知道什么**
3. **他为什么要听**（利害、任务、担心）
4. **听完要他能做什么或决定什么**

禁止默认「对方和我一样懂」。有疑问时按**更不懂的那一侧**解释，再按需加深。

### 2. 結論から言う

- 先给答案/主张/要做什么，再给理由与背景  
- 背景故事再有趣，也不要堵在结论前面  
- 标题/首句尽量是**主张句**，不是主题词（坏：「关于预算」／好：「预算应先砍广告，保研发」）

需要叙事铺垫时：最多 1–2 句钩子 → 立刻落结论 → 再展开。

### 3. 噛み砕く（术语与抽象）

对每个行话做三选一：

| 处理 | 何时 |
|------|------|
| **删除** | 对方不需要这个词也能做事 |
| **翻译** | 必须保留概念 → 用日常话 + 必要时括号留术语 |
| **举例** | 抽象概念 → 一个具体场景或たとえ |

翻译公式：`日常说明（术语）` 或 `术语＝一句话人话`。  
同一术语全文只定义一次，之后可复用短名。

### 4. 具体で語る

优先替换模糊词：

- 「很多 / 最近 / 相关方 / 适当优化」→ 数字、时间、人名/角色、动作  
- 抽象主张旁边至少挂 **1 个例子或たとえ**  
- たとえ要贴切：同一领域优先；跨领域时点明「类似点是什么」

### 5. 事実と意見を分ける

- 事实：可核对（数据、事件、规定）  
- 意见：判断、建议、预测——显式标成「我认为 / 建议 / 预测」  
- 禁止把推测写成既定事实；不确定就写清不确定与依据

### 6. わかりやすい文

- **一句一意**；长句拆开  
- **主語を明確に**（谁做了什么）；少用无主語的「被…化了」堆砌  
- 口语能懂的书面语优先；炫技同义词不要  
- 段落：先结论句，再支撑；新意新段

### 7. 伝える前に調べ、聞く

- 讲不清往往是自己还没懂 → 先补齐「为何如此」再解释  
- 双人场景：先听对方卡在哪、已有什么误解，再对症说明  
- 准备问答：预想「所以呢？」「和我有什么关系？」「有何证据？」

## 体裁配方

### 说明文 / 邮件 / 文档

```
结论（1 句）
→ 为何重要（対相手）
→ 要点 2–4 条（各条：主张 + 一句理由或例子）
→ 事实依据（可折叠/附注）
→ 下一步（对方要做什么）
```

### 口头讲解 / 汇报

```
30 秒版结论
→ 「用一个例子说」
→ 细节按需加深（分层：先人话，再术语）
→ 复述确认：「目前理解是…对吗？」
```

### 难概念（教学向）

1. 日常类比  
2. 正式定义（短）  
3. 边界：容易混的「不是什么」  
4. 一个最小例子  
5. （可选）术语原文  

## 审稿清单（既有文）

按序标问题，每条给改法：

1. 相手与目的是否写清/可推断？  
2. 结论是否在前 3 行内？  
3. 未翻译术语列表  
4. 何处只有抽象没有例子  
5. 事实/意见是否缠在一起  
6. 长句、缺主語、一段多意  
7. 读完能否用一句话复述重点


## 反模式

- 用术语密度证明专业  
- 先讲百年史再讲今天要做什么  
- 「众所周知」「无需赘言」——对相手往往并不众所周知  
- 模糊主语 + 名词化（「进行优化的推进」）  
- 把意见写成事实，或把个别例子夸成普遍规律  
- 为「有文采」加长句和生僻词  

## 边界

- 不编造数据、引语、新闻事实；缺材料就标【待补】  
- 不替代法律/医疗等专业结论，只负责说明结构与措辞  
- 需要严密论证塔时，先/并行用 `minto-pyramid`；本 skill 负责「说人话」层  
- 需要版式图表时用 `tsutawaru-*`，不要和本书混用
